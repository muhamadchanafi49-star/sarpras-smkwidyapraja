Panduan Publikasi Website Secara Umum (Online)

Aplikasi web Sistem Informasi SARPRAS SMK Widya Praja Ungaran ini dibuat dalam arsitektur **Single-File Ready Web Application** (HTML + Tailwind + Pure JavaScript). Anda dapat mempublikasikan website ini langsung agar bisa diakses seluruh guru, siswa, dan publik secara gratis maupun menggunakan domain sekolah.

Cara 1: GitHub Pages (Gratis 100%)

Sangat direkomendasikan untuk hosting cepat & gratis tanpa server backend tambahan.

  1. Unduh file halaman ini dengan menekan tombol **"Download Source File HTML"** di bawah.
  2. Buat akun di GitHub.com.
  3. Buat repository baru, contoh: sarpras-smkwidyapraja.
  4. Upload file ini dan beri nama index.html.
  5. Buka menu **Settings -> Pages**, pilih branch `main` lalu Simpan.
  6. Website Anda langsung aktif online di URL: username.github.io/sarpras-smkwidyapraja.

Cara 2: Netlify Drop (Drag & Drop)

Metode paling instant tanpa perlu coding atau Git command.

  1. Unduh file index.html aplikasi ini.
  2. Buka app.netlify.com/drop.
  3. Drag & drop folder yang berisi file index.html tersebut.
  4. Netlify akan memberikan domain acak gratis (misal: sarpras-smk.netlify.app) dalam 5 detik!
  5. Anda juga dapat menghubungkan domain resmi SMK (misal: sarpras.smkwidyapraja.sch.id).

Cara 3: Hosting cPanel SMK

Menggunakan server web resmi sekolah yang sudah ada.

  1. Login ke cPanel web sekolah SMK Widya Praja.
  2. Buka menu **File Manager -> public_html** (atau buat subdomain sarpras.smkwidyapraja.sch.id).
  3. Upload file index.html ke direktori tersebut.
  4. Selesai! Website langsung dapat diakses secara publik oleh siswa dan guru.

Siap Dipublikasikan Sekarang!

Unduh seluruh kode HTML aplikasi ini beserta konfigurasi data multiuser untuk langsung diunggah ke server web hosting.
